# 所有省份的描述

为《欧陆风云4》全部 3,272 个陆地省份提供英文和简体中文介绍。打开省份，鼠标停在风景图右侧的卷轴按钮上即可；未殖民省份的按钮在风景图内靠右。

需要同时启用中文模组 Chinese Language Mod for 1.37（工坊 2976470733）才显示中文，否则显示英文；其他汉化模组识别不到。装不装 Bigger UI 都能用。脚本按钮会改变校验码，所以不兼容成就。

手动安装：把发布的 ZIP 解压到 `文档\Paradox Interactive\Europa Universalis IV\mod\`，让 `province_descriptions` 文件夹和 `province_descriptions.mod` 并排，然后在启动器里启用。不要同时启用手动副本和工坊副本。

介绍由 AI 辅助、依据公开资料（主要是维基百科）写成，并逐条审阅过。发现错误欢迎在工坊留言。正文用 CC BY-SA 4.0，工具用 MIT，见 LICENSE 和 CREDITS.md；每个省份的资料来源在 `sources/sources.jsonl`。
